# 安全、隐私与执行边界

## 信任边界

上传资料、模型输出、用户补丁、体验参与者输入和分享 token 都不可信。资料里的“忽略指令”“访问网址”等只是材料文本，不能改变系统/工具授权。模型输出必须经 Schema、语义、来源、状态和浏览器检查；拒绝不代表事实已认证。

| 威胁 | 约束 | 关联验收 |
|---|---|---|
| IDOR 跨项目 | 子资源同项目外键、应用授权、分享仅访问投影 | F01-AT02、F09-AT01 |
| 提示注入/越权工具 | 资料与指令分离、工具二次授权、无任意 URL/SQL/shell | F03-AT03、F09-AT01 |
| XSS/上传执行 | 纯文本；文件签名/尺寸；禁 SVG/HTML/脚本；CSP | F02-AT01、F04-AT04 |
| 路径穿越/SSRF | 只接资源 ID，服务端生成路径/预览句柄，出口白名单 | F09-AT01 |
| 浏览器逃逸影响面 | 无密钥/宿主卷/容器套接字、限 CPU/内存/墙钟、独立来源 | F05-AT03、F09-AT01 |
| 撤销不完整 | 页面/规格/素材/出处同策略、private no-store、不放公共 CDN | F08-AT03 |
| 密钥/原文泄露 | 服务端凭据、日志脱敏、trace 仅所有者、导出清单扫描 | F08-AT04、F09-AT03 |

## 身份与网络

本地开发身份仅用于回环地址，生产环境发现开发身份适配器直接拒绝启动。生产提供方待确定，至少要求安全会话、服务端注销、HttpOnly/Secure cookie、SameSite 与 CSRF 防护（若用 cookie），CORS 固定允许来源。不能把 project_id 或任意 user_id 当凭证。

HTTP 限流按 actor/project/IP，上传流式先限大小，解析无有效文本不成功。试玩预览句柄限时、固定资源范围；生产分享和私有预览使用独立来源或等效隔离，禁止预览借主站 cookie 调管理 API。

## 模型与执行器

Provider 凭据仅服务端适配器持有：生成 Worker 与 API 在线对话用例按最小权限注入；浏览器/静态包/日志不含。阶段工具有最小权限；模型无法改预算、测试器、Schema、必要目标、审核结论、分享设置或原文。JSON Patch 操作路径和对象归属都要检查，不能仅检查字符串前缀；需标准解析 JSON Pointer，并防转义绕过。

浏览器执行器只允许本次冻结预览域名与资源；阻断重定向到其他主机、私有网段、元数据地址和任意本机端口，允许的受控预览地址单独配置。限制上传解压、PDF 解析和图片解码资源。隔离通过真实容器/进程权限与网络规则测试，不能靠提示词或文档声称已隔离。

## 分享、缓存与许可

分享 token 至少 256 位随机熵，数据库仅存加盐/密码学哈希或安全等效值；不得写访问日志，路径日志需脱敏。分享 API 对内容使用 Cache-Control: private,no-store，不启用可绕过撤销的 Service Worker；每次资源请求校验 active/expiry/version。撤销阻止后续在线请求，已加载内存、截图、下载副本无法抹除。

每项可导出素材/引文需公开使用许可说明。许可证缺失/撤销阻断正式导出和分享；带出处不等于有公开权。公开投影仅含批准引文与必要位置，不暴露私有全文、内部提示、模型原始输出或运行 trace。

## 数据保留与删除

首版不要求学生姓名/联系方式。AI 对话为核心功能，聊天可能含自发输入的个人信息；按用途最小保留、脱敏、访问控制与删除策略处理，不默认用于训练或对外共享。项目删除前展示影响，撤销分享和对话授权、停止活动任务、清理会话/原文/素材/备份。保留期限由试点机构确认，生产上线前不能留为空泛默认。

## 对话与 Agent 作用域

创作 Agent 可按所有者权限访问项目材料；Guide 只访问固定发布版本、允许公开证据投影与当前体验会话。身份/项目/版本/角色不可由模型改写；引用经服务端校验，摘要不能提升权限。模型建议的提示/导航是白名单展示动作，不能设置任务成功或发布。

分享撤销/到期同步阻断对话创建、后续流式输出及历史回复读取；取消在检查点停止新工具/模型调用，已有费用保留。跨参与者隔离、提示注入、私有全文索取、旧版本引用、配额和部分回复必须有负向验收。

隐私删除和不可变历史冲突时，以有效删除要求为准：清除内容，保留不含个人正文的最小审计墓碑；已下载包和第三方副本不可保证删除，需如实说明。备份轮换、删除完成状态和失败原因可追溯。生产合规要求应另行核对适用政策，本文件是工程边界而非法律合规证明。
