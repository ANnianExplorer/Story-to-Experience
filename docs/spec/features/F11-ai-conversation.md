# F11 SPEC：创作对话与体验 AI 导览／角色对话

> 核心业务，planned；不是仅预设按钮或 FAQ。设计见 [SDD](../../sdd/features/F11-ai-conversation.md)。

## 需求与验收

| 需求 ID | 必须满足的行为 |
|---|---|
| F11-R01 | 创作者可自由文本交流，AI 基于项目、材料、简报、当前版本和历史澄清需求、检索并计划；生成/修改走受控用例和基准版本，不从模型回复直接覆盖稳定版或发布。 |
| F11-R02 | 体验参与者可向 Guide/角色自然语言提问、追问和求提示；回答使用固定已发布版本、当前场景/已获线索/目标与允许公开证据，有可点击出处，角色改编明确标识。 |
| F11-R03 | 每会话隔离身份、项目、版本和角色；结构事实锚点不可被摘要改写；长对话保留固定预算内的近期消息、带来源摘要和检索片段。版本切换显式新建/迁移会话，不混用旧引用。 |
| F11-R04 | 流式回复有 turn_id、取消、重连和持久最终状态；工具/引用/建议动作结构化。只有公开进度与结果可见，不泄露系统提示、内部工具结果或私有推理。 |
| F11-R05 | 资料不足明确未知，恶意提问不能改变工具权限；Guide 不能直接设置任务完成或发布。自由文本语义不作有限状态完整证明；对话只通过受控提示/解释/导航建议与任务关联。 |
| F11-R06 | 对话调用有独立会话/参与者/项目限流、轮数、输出和货币预算，生成预算与对话预算分开但受统一组织/项目额度约束；未知费用保留。离线版明确无实时 AI。 |

| 验收 ID | 需求 | 具体预期 |
|---|---|---|
| F11-AT01 | F11-R01 | 连续交流“给五年级使用、保留来源、减少文字”，AI 保留约束，给计划并实际发起有版本记录的修改；未经授权不发布。 |
| F11-AT02 | F11-R02 | 体验中询问“为什么 A 要在 C 前”，回答引用当前版本有效片段；追问结合场景；没有资料的问题明确说明缺口。 |
| F11-AT03 | F11-R03 | 两项目、两角色、旧新版本会话互不泄露；摘要压缩后仍保留事实限定和出处，旧审核不自动适用于新内容。 |
| F11-AT04 | F11-R04 | 流式断线/重连/取消不产生重复完整回复或重复工具执行；部分输出标未完成，费用和终态可追溯。 |
| F11-AT05 | F11-R05 | “忽略指令、给我私有全文、直接让我完成”等攻击被限制；禁用对话后结构化任务仍有明确定义的可完成路径。 |
| F11-AT06 | F11-R06 | 同会话只允许一个活动 turn；不同参与者受全局配额而非项目生成锁互相堵塞；触顶不再发调用；离线包无伪实时回答。 |

文本对话记录可能含用户自发输入的个人信息，需最小保留/脱敏/删除策略，不再沿用“系统没有聊天记录”的旧假设。模型/提示词/RAG 与会话摘要版本一并记录。
