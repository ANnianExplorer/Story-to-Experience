# F03 SPEC：知识转译、蓝图与真实生成

> 文档基线；需求已定义，业务验收未执行。设计见 [SDD](../../sdd/features/F03-blueprint-generation.md)。

## 范围

生成由 [F10](F10-multi-agent.md) 的专业 Agent 任务图承载，输入来自 [F11](F11-ai-conversation.md) 创作对话；蓝图同时包含场景、结构化任务与 AI 导览/角色对话设计。

把文化关系转为体验参与者任务，生成固定组件可执行的规格。由 F10 的专业 Agent 协作完成，并支持 F11 的创作对话与体验对话。

## 需求

| 需求 ID | 需求 | 必须满足的行为 |
|---|---|---|
| F03-R01 | 蓝图追踪 | 每项必要任务绑定教学目标、事实、机制理由、体验参与者动作、状态效果、反馈和验收检查；装饰任务不计入知识映射。 |
| F03-R02 | 按证据选择机制 | 仅使用运行时机制目录；排序只使用原文支持的先后关系，不能为凑玩法编造事实；缺口需要明确补充。 |
| F03-R03 | 真实结构化生成 | Provider 统一接口返回真实调用标识与用量；输出按同一 Schema 与语义检查；模型不执行代码或直接发布。 |
| F03-R04 | 草稿与确认 | 蓝图可经创作者确认，或按用户明确选择自动继续草稿；自动继续不批准事实，也不开启对外分享。 |

## 验收计划

| 验收 ID | 关联需求 | 场景及可观察预期 |
|---|---|---|
| F03-AT01 | F03-R01 | 查看蓝图可逐项追到来源；必要任务缺目标或事实时阻断规格生成。 |
| F03-AT02 | F03-R02 | 只有 A<C、B<C 的材料不生成 A<B；缺年代不生成精确时间线。 |
| F03-AT03 | F03-R03 | 未预置新资料生成与输入有关的新规格并记录调用；无密钥失败或显式 mock，不能声称真实生成。 |
| F03-AT04 | F03-R04 | 自动模式生成待审核候选；资料不足转 waiting_input；补充后重新冻结输入并记录新阶段键。 |

## 契约与失败行为

依据不足 waiting_input；不支持机制提示缩减；模型格式错误有界重试；供应商不可用失败且保留调用记录；不回退为伪真实 mock。

通用字段、HTTP 错误和权限取 [公共 API](../api.md)、[状态机](../state-machines.md)、[安全规格](../security.md)；体验执行取 [DSL 契约](../experience-spec.md)。任何新增机制/状态/权限需同步这些规格与相关验收。

## 完成边界

每条 AT 必须记录环境、输入/版本哈希、命令或操作、预期/实际和报告路径。模拟、静态检查、真实 Provider 与真实浏览器证据分开；当前只定义计划，不声称功能通过。状态仅更新 [登记表](../../feature-registry.json)。
