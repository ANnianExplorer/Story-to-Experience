# F04 SPEC：ExperienceSpec、共享引擎与体验运行端

> 文档基线；需求已定义，业务验收未执行。设计见 [SDD](../../sdd/features/F04-runtime-player.md)。

## 范围

在线体验必须接入 [F11 AI 导览／角色对话](F11-ai-conversation.md)，支持自由文本与连续追问。现有三机制是确定性任务基座，不是全部产品交互；对话只通过受控提示/解释/导航与任务关联。

无需模型与数据库即可播放合法手工规格，三类机制共享明确动作语义，确定性互动可独立运行；在线体验通过 F11 提供真实 AI 导览与角色对话。

## 需求

| 需求 ID | 需求 | 必须满足的行为 |
|---|---|---|
| F04-R01 | 原子执行 | 按 runtime DSL 验输入、前置和当前场景；成功一次性设置声明标记并最多一次跳转，失败不改逻辑状态。 |
| F04-R02 | 三类机制 | 热点获取线索；分支区分成功与错误反馈；排序输入必须是完整唯一排列，并按偏序而非唯一答案判断。 |
| F04-R03 | 完成与可重玩 | 完成页仅在必要标记全满足时进入；来源和提示 UI 不改变逻辑状态；重玩还原入口和所有 false 标记。 |
| F04-R04 | 移动与无脚本 | 纯文本和授权静态图片；禁 HTML/eval；键盘/触屏可操作，排序有上移/下移替代拖拽。 |
| F04-R05 | 叙事视觉与 React 动效 | 体验运行端遵守海盐与纸页主题，短标题/场景/线索/排序使用统一动效；减弱时即时显示，动画中断不改变动作结果或来源可用性。 |

## 验收计划

| 验收 ID | 关联需求 | 场景及可观察预期 |
|---|---|---|
| F04-AT01 | F04-R01 | 错误 action/未知 flag/不满足前置不改状态；无显式跳转保持场景；完成后重复任务无效果。 |
| F04-AT02 | F04-R02 | ABC 与 BAC 均通过 A<C、B<C；ACB 失败；缺项/重复/未知元素均拒绝。 |
| F04-AT03 | F04-R03 | 跳过必要任务不能完成；开关来源卡不解锁任务；重玩后可再次完成。 |
| F04-AT04 | F04-R04 | 脚本文本只作为文本显示；360px 视口和键盘能完成；实际手机留待 F09 人工验收。 |
| F04-AT05 | F04-R05 | 标题只播一次、总入场≤800ms；减少动效时无平移/缩放/逐组等待；动画中取消/卸载与禁动画运行得到相同引擎结果；排序焦点和来源入口始终可用。 |

## 契约与失败行为

未知运行时拒绝播放；非法动作/坏排序返回错误且状态不变；错误答案给依据和重试；加载损坏清单不执行。

通用字段、HTTP 错误和权限取 [公共 API](../api.md)、[状态机](../state-machines.md)、[安全规格](../security.md)；体验执行取 [DSL 契约](../experience-spec.md)。任何新增机制/状态/权限需同步这些规格与相关验收。
