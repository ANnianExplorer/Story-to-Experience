# F08 SPEC：内容审核、分享、导出与撤销

> 文档基线；需求已定义，业务验收未执行。设计见 [SDD](../../sdd/features/F08-review-delivery.md)。

## 范围

V2：正式在线体验包含经授权的 Guide 对话；撤销同时影响资源与会话。离线 ZIP 是资料/确定性互动版，无实时 AI，必须在导出前和包内说明能力差异。对话设定、公开证据范围与提示策略也纳入版本审核。

让创作者清楚选择交付固定版本，有出处、有许可、审核可追溯；在线撤销完整但不承诺撤回下载副本。

## 需求

| 需求 ID | 需求 | 必须满足的行为 |
|---|---|---|
| F08-R01 | 人工内容审核 | 审核记录 reviewer、版本/语义哈希、事实/任务范围、approved/needs_changes 及说明；模型不能提交 approved。 |
| F08-R02 | 交付双门槛 | 正式分享、正式 ZIP 和 stable 晋级要求所有必需技术报告 passed、完整内容批准、当前授权有效且哈希匹配。 |
| F08-R03 | 固定分享与撤销 | 随机令牌至少 256 位、仅存哈希、固定 version_id、有效期；页面/规格/图片/出处投影统一校验，禁止永久公共资源捷径。 |
| F08-R04 | 最小静态导出 | 仅包含体验运行端、允许公开的规格/引文/素材和许可清单；无密钥、私有全文、内部提示/日志；断网本地静态服务器可玩。 |

## 验收计划

| 验收 ID | 关联需求 | 场景及可观察预期 |
|---|---|---|
| F08-AT01 | F08-R01 | 关键陈述未覆盖不能总体 approved；语义改动变 pending；纯样式相同语义哈希可引用旧审查记录。 |
| F08-AT02 | F08-R02 | 技术通过但待审/超时未知/报告哈希过期均拒绝；显式 draft ZIP 带待审水印且仅所有者下载。 |
| F08-AT03 | F08-R03 | 修改项目新版本不改变旧分享；撤销后直接请求旧图片/规格同样失败；缓存不可绕过撤销。 |
| F08-AT04 | F08-R04 | 扫描 ZIP 清单无内部文件；断网完成任务/出处/重玩；导出界面说明已下载文件不可撤回。 |

## 契约与失败行为

未审/失败/未知拒绝正式交付；到期/撤销/错误 token 所有资源失败；导出扫描发现私有全文/密钥中止。

通用字段、HTTP 错误和权限取 [公共 API](../api.md)、[状态机](../state-machines.md)、[安全规格](../security.md)；体验执行取 [DSL 契约](../experience-spec.md)。任何新增机制/状态/权限需同步这些规格与相关验收。

## 完成边界

每条 AT 必须记录环境、输入/版本哈希、命令或操作、预期/实际和报告路径。模拟、静态检查、真实 Provider 与真实浏览器证据分开；当前只定义计划，不声称功能通过。状态仅更新 [登记表](../../feature-registry.json)。
