# F09 SPEC：安全、部署、恢复与评估

> 文档基线；需求已定义，业务验收未执行。设计见 [SDD](../../sdd/features/F09-operations-security.md)。

## 范围

用真实运行证据证明可部署和可恢复，记录隐私、成本与能力限制；自审不作为安全认证。

## 需求

| 需求 ID | 需求 | 必须满足的行为 |
|---|---|---|
| F09-R01 | 安全负向测试 | 覆盖跨项目访问、恶意资料提示、脚本注入、路径/URL 越界、分享资源绕过与试玩出口；密钥不进入浏览器或 trace。 |
| F09-R02 | 可恢复部署 | Compose 目标拓扑、持久卷、迁移和兼容检查有清单；备份数据库与文件并实际还原固定版本与报告。 |
| F09-R03 | 观测与成本 | 按 run/provider/model/版本记录耗时、次数、错误、修复、搜索与费用状态；模型失败/重试也计入，unknown 独立报告。 |
| F09-R04 | 真实评估与发布 | 固定正常集和故障集分开，报告原始分母、人工支持率、实际手机与残余风险；不以通关证明学习效果。 |

## 验收计划

| 验收 ID | 关联需求 | 场景及可观察预期 |
|---|---|---|
| F09-AT01 | F09-R01 | 恶意文档不能改变工具权限；执行器不能访问宿主/模型密钥/任意外网；每类失败有测试与原因。 |
| F09-AT02 | F09-R02 | 空环境按说明启动；恢复后文件哈希、来源、版本和报告完整；只有备份命令日志不能算恢复通过。 |
| F09-AT03 | F09-R03 | 能追到一次失败的阶段和真实费用窗口；日志脱敏；成功交付成本分母为成功交付数，失败费用保留。 |
| F09-AT04 | F09-R04 | 至少一台实际手机完成；20 份材料的计划与实际样本数分开；未跑项 not_run；发布不宣称全覆盖或教育收益。 |

## 契约与失败行为

缺生产身份/沙盒/恢复证据阻断公开发布；依赖缺失明确失败；日志或导出发现密钥立即撤销并修复，不保留在报告中。

通用字段、HTTP 错误和权限取 [公共 API](../api.md)、[状态机](../state-machines.md)、[安全规格](../security.md)；体验执行取 [DSL 契约](../experience-spec.md)。任何新增机制/状态/权限需同步这些规格与相关验收。

## 完成边界

每条 AT 必须记录环境、输入/版本哈希、命令或操作、预期/实际和报告路径。模拟、静态检查、真实 Provider 与真实浏览器证据分开；当前只定义计划，不声称功能通过。状态仅更新 [登记表](../../feature-registry.json)。
