# F01 SPEC：项目、身份与创作者工作台

> 文档基线；需求已定义，业务验收未执行。设计见 [SDD](../../sdd/features/F01-project-workbench.md)。

## 范围

让创作者管理自己的材料与体验，区分生成进度、技术质量和内容审核。首版不做组织管理与多人协作。

## 需求

| 需求 ID | 需求 | 必须满足的行为 |
|---|---|---|
| F01-R01 | 创建与归属 | 已认证创作者创建项目及受众、时长、目标简报；owner 由服务端会话决定，忽略客户端伪造的 owner_id。 |
| F01-R02 | 逐资源授权 | 项目、事实、任务、版本、报告、附件均按归属授权；其他用户读取统一返回不泄露对象存在性的 404。 |
| F01-R03 | 工作台状态 | 同时显示任务生命周期、阶段、技术结论、内容结论和费用状态；模拟模式显式标记；不自动开启分享。 |
| F01-R04 | 可恢复交互 | 修改框在网络失败和 409 时保留文本；SSE 从序号续传；取消完成后不继续显示正在生成。 |
| F01-R05 | 统一视觉与低干扰动效 | 工作台使用前端 Token 和响应式规范；微交互支持系统/本地减弱设置；来源正文清晰、焦点可见，动画不延迟真实任务状态。 |

## 验收计划

| 验收 ID | 关联需求 | 场景及可观察预期 |
|---|---|---|
| F01-AT01 | F01-R01 | 创建后可在列表进入工作台；传入他人 owner_id 不改变实际归属；未认证请求为 401。 |
| F01-AT02 | F01-R02 | 用用户 B 的会话读取用户 A 的项目及子资源均为 404，不能仅项目首页受保护。 |
| F01-AT03 | F01-R03 | 等待补充/技术未知/费用未知分别显示；mock 预览有标识；刷新后还原持久快照。 |
| F01-AT04 | F01-R04 | 断线补发事件不重复；服务要求重取快照时收敛到真实状态；取消后界面与任务快照一致。 |
| F01-AT05 | F01-R05 | 360/390/768/1024/1440 视口无横溢；来源、进度、版本在键盘下可用；减少动效后无非必要移动或延迟，Token 与生成 CSS 一致。 |

## 契约与失败行为

身份过期提示重新登录；事件断档重新取快照；无来源/无版本显示可操作空态；409 保留用户输入并说明重新加载。

通用字段、HTTP 错误和权限取 [公共 API](../api.md)、[状态机](../state-machines.md)、[安全规格](../security.md)；体验执行取 [DSL 契约](../experience-spec.md)。任何新增机制/状态/权限需同步这些规格与相关验收。

## 完成边界

每条 AT 必须记录环境、输入/版本哈希、命令或操作、预期/实际和报告路径。模拟、静态检查、真实 Provider 与真实浏览器证据分开；当前只定义计划，不声称功能通过。状态仅更新 [登记表](../../feature-registry.json)。
