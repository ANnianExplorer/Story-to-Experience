# F02 SPEC：材料、事实与证据快照

> 文档基线；需求已定义，业务验收未执行。设计见 [SDD](../../sdd/features/F02-sources-evidence.md)。

## 范围

上传授权资料并提供稳定可核对的证据，保留传说和改编性质，不用网页抓取或 OCR 补全资料。

## 需求

| 需求 ID | 需求 | 必须满足的行为 |
|---|---|---|
| F02-R01 | 受限输入 | 按产品限额接收正文、文本 PDF 和授权图片，验证文件签名及解码尺寸；不接受 SVG/脚本或任意磁盘路径。 |
| F02-R02 | 稳定定位 | 片段定位至规范化解析文本，start/end 为 Unicode 码点半开区间；记录页、段、解析版本、quote、text_hash。 |
| F02-R03 | 内容性质 | 事实使用 supported/legend/adaptation/unconfirmed；supported 和 legend 必有证据；改编不能伪造出处，待确认不能作唯一关键答案。 |
| F02-R04 | 依赖失效 | 维护证据→事实→目标→任务→规则→检查的引用；替换/删除关键证据后相关内容待审并阻断新正式交付。 |

## 验收计划

| 验收 ID | 关联需求 | 场景及可观察预期 |
|---|---|---|
| F02-AT01 | F02-R01 | 文本 PDF 有页码；扫描 PDF 明确拒绝；伪装图片/超尺寸被阻断且未进入生成。 |
| F02-AT02 | F02-R02 | 用规范化文本切片等于 quote；中文与补充平面字符不发生 UTF-16 偏移；源文件更新不篡改旧定位。 |
| F02-AT03 | F02-R03 | 传说仍标传说；虚构对白标改编；无依据工序生成缺口，不能变为确定顺序。 |
| F02-AT04 | F02-R04 | 删除唯一证据，影响清单包含对应任务和检查；旧报告不自动适用于新快照，旧公开分享按撤销策略关闭。 |

## 契约与失败行为

扫描 PDF 为 NO_EXTRACTABLE_TEXT，不是成功空白；超额/类型错误返回明确错误；冲突事实保持待确认；解析超时不覆盖旧快照。

通用字段、HTTP 错误和权限取 [公共 API](../api.md)、[状态机](../state-machines.md)、[安全规格](../security.md)；体验执行取 [DSL 契约](../experience-spec.md)。任何新增机制/状态/权限需同步这些规格与相关验收。

## 完成边界

每条 AT 必须记录环境、输入/版本哈希、命令或操作、预期/实际和报告路径。模拟、静态检查、真实 Provider 与真实浏览器证据分开；当前只定义计划，不声称功能通过。状态仅更新 [登记表](../../feature-registry.json)。
