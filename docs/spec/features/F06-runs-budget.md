# F06 SPEC：持久任务、恢复、事件与费用

> 文档基线；需求已定义，业务验收未执行。设计见 [SDD](../../sdd/features/F06-runs-budget.md)。

## 范围

让生成可取消、可恢复、有限成本，重复投递不会重复提交业务版本；不承诺外部模型恰好执行一次。

## 需求

| 需求 ID | 需求 | 必须满足的行为 |
|---|---|---|
| F06-R01 | 提交幂等 | 项目内活动生成/修订任务唯一；Idempotency-Key 同 actor/route/project 及相同摘要返回原任务，换 payload 返回 409。 |
| F06-R02 | 租约与恢复 | 抢占增加 fencing token；提交同时检查 token、状态、数据库时间租约；阶段幂等键含输入哈希和阶段版本。 |
| F06-R03 | 事件与取消 | 持久事件按序号续传；取消幂等且停止新调用、失效 token、拒绝迟到结果；终态不可倒退。 |
| F06-R04 | 预算与未知费用 | 调用前原子预留次数/货币/时间预算；最多 12 次（含重试）、两轮修复；实际/估算/未知费用分开，取消照实结算。 |

## 验收计划

| 验收 ID | 关联需求 | 场景及可观察预期 |
|---|---|---|
| F06-AT01 | F06-R01 | 两次相同请求只有一个 run；不同键并发仍只能一个活动任务；幂等复用不算新模型调用。 |
| F06-AT02 | F06-R02 | 杀死 Worker 后新 Worker 复用已提交阶段；旧 Worker 返回时不能写阶段/版本；无重复版本提交。 |
| F06-AT03 | F06-R03 | 断线按 Last-Event-ID 恢复；取消与完成竞争仅一个结果；已完成取消返回当前终态。 |
| F06-AT04 | F06-R04 | 并发调用不能超额预留；预算不足不启动调用；超时未知不记零且保留占用或按保守上界结算。 |

## 契约与失败行为

Worker 失联后租约过期再抢占，旧 token 拒绝；超时未知用量标 unknown；等待输入释放租约但保留活动占位。

通用字段、HTTP 错误和权限取 [公共 API](../api.md)、[状态机](../state-machines.md)、[安全规格](../security.md)；体验执行取 [DSL 契约](../experience-spec.md)。任何新增机制/状态/权限需同步这些规格与相关验收。
