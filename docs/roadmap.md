## 最先贯通两条纵向链

创作者：上传一份新材料 → 对话说明目标 → 看到可追踪计划和专业 Agent 委派 → 得到有依据的新候选。

参与者：进入固定体验 → 自然语言提问与追问 → Guide 使用场景/线索和公开证据回答 → 查看出处并继续互动。

纯函数引擎、三类固定机制仍要完成，但不以长期排序或界面试作替代这两条链。若时间不足，应缩减主题、场景数量和非必要编辑器，不能再次静默删掉多 Agent 或 AI 对话。

## 预算与恢复

一次生成 run 的 12 次调用由所有 Agent 共享，修复最多两轮；模型/工具调用必须在服务端预留预算。在线对话有独立会话/参与者/项目额度和统一总费用限制，不与项目生成锁互相堵塞。

任务和会话恢复分别验收。外部结果未知可能重复计费，费用 unknown 保留；取消、超时和分享撤销都停止后续授权行为。默认不得以缺模型凭据自动切换 mock 并宣称真实运行。

## 计划边界

具体模型、团队、身份方案、材料许可、审核人和生产环境未定；三人六周只是旧规划假设，不是交付承诺。当前所有业务功能 implementation_status=planned。阅读 [V2 总览](architecture-and-design-v2.md)、[F10 SDD](sdd/features/F10-multi-agent.md)、[F11 SDD](sdd/features/F11-ai-conversation.md) 后领取任务。
