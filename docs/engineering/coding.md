# 编码与模块规范

前端页面/组件同时遵守 [视觉与动效规范](../frontend/README.md)：Token 为统一源，CSS+Motion for React 分工，支持减少动效；不得让动画回调决定业务状态。

## 类型和文件

TS 使用 strict，边界接 unknown 后校验，避免 any 扩散。Python 领域/用例参数与返回类型明确，数据库行转换为领域对象后再使用。不以控制器、组件或 LangGraph 节点作为公共逻辑复用层。

公共数据从 Schema/OpenAPI 派生类型，不手工维护两份。生成文件放明确目录并由检查确认可再生，业务代码不能 import 内部模块私有实现。一个模块只维护本领域不变量；大函数按用例与纯规则拆分，不按行数机械拆文件。

## 错误与异步

错误有稳定 code、用户消息、关联对象和 retryable；内部堆栈仅受控日志。捕获已知错误转领域结果，未知错误不吞掉，不把损坏数据返回空集。超时/取消传播到 Provider 和执行器；迟到结果仍经过 token 条件提交。

外部重试最多两次，合计最多三次尝试，全部计入 12 次模型调用上限；退避带抖动但不进入体验参与者状态。4xx 权限/规则错误不自动重试；429/暂时 5xx 按总预算重试，未知结果先核对供应商请求记录。

## 状态、时间与费用

UTC 入库，界面显示用户时区。租约用数据库时间。费用禁止浮点累计；存币种、供应商定价版本、usage、actual/estimated/unknown，不混币种直接相加。配置限额有上界和来源，不在 UI 与 Worker 各写一份默认值。

纯引擎不可读全局随机数、环境、DOM、网络和时钟。体验参与者展示状态不隐式参与解锁。数据库写入经应用服务，进程不是逻辑所有权边界。

## 依赖与提交

先选当前需要的依赖，锁定实际版本和许可，使用锁文件重现安装；不提前增加 Redis/Kubernetes/向量库。TS 使用 pnpm 工作区、Python 用独立环境及锁定依赖，具体工具版本在代码首次落地时记录。

提交围绕单一目标；不提交密钥、原文私有材料、缓存、构建产物和浏览器 trace 正文。大型证据存受控文件存储，仓库只存脱敏摘要/清单/哈希。示例环境文件只含占位值。
