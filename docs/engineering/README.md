# 工程规则核心目录

[CLAUDE.md](../../CLAUDE.md) 是总约束；本目录解释如何执行，不增加重复事实源。

| 文档 | 用途 |
|---|---|
| [工作流与变更](workflow.md) | 准入、任务、小步实现、状态和证据 |
| [编码规范](coding.md) | 分层、类型、错误、数据和依赖 |
| [前端规范](../frontend/README.md) | 用户选定参考的视觉与 React 动效标准 |
| [文档治理](documentation.md) | 唯一真相、编号、更新与检查范围 |
| [三视角自审](review.md) | 开发者、组长、技术负责人 |
| [ADR 模板](templates/adr.md) | 新增长期决策 |
| [功能模板](templates/feature.md) | 新增 SPEC/SDD 的最小内容 |
| [任务与证据模板](templates/task-and-evidence.md) | 可领取任务、检查和交付记录 |

参考 WorkExpert 的闭环，不照搬它的工具栈和文件数量。本项目不要求每个功能复制十余个模板文件；复杂到难以维护时再拆分，索引/ID/状态仍须唯一。
