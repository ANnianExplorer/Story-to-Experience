# 产品基线

叙境服务已有文化文本、需要制作 3—5 分钟探索活动的研学创作者。输入经授权资料、受众、时长和教学目标，输出有出处、能操作、可修改的体验。用户价值仍需试用验证，不宣称已证明教育收益。

**当前核心范围：多 Agent 协作创作＋创作者 AI 共创对话＋体验参与者 AI 导览／角色对话。** 依据用户纠正，当前总览为 [V2 架构](architecture-and-design-v2.md)，上一版排除这些能力的收缩不再适用。

追踪链：`SourceSpan → Claim → LearningObjective → Task → Rule → Check`。热点提供线索，分支体现有依据的处境，排序使用实际支持的偏序；复盘对应行动与知识。装饰剧情可存在，但不能伪装史实或计入必要知识任务。

## MVP 边界

正文、文本 PDF、授权 PNG/JPEG/WebP；热点、分支、排序及 AI 引导对话；多 Agent 计划/证据/设计/构建/审校/修复；创作者共创；来源卡；程序检查与浏览器试玩；不可变版本、审核与受保护在线分享。离线资料包保留确定性互动和固定资料，明确无实时 AI。

暂不做 OCR、联网补事实、任意代码执行、复杂经济、多人实时编辑、支付和组织审批。开放文本 AI 对话在本次范围内，围绕授权资料、角色与当前场景回应；不是只有预设 FAQ。React Flow 场景图不阻塞核心对话/协作链。

## 初始工程限额

| 项 | 上限/规则 |
|---|---|
| 正文 | 项目源快照合计 20,000 个 Unicode 码点 |
| PDF | 单文档 30 页；扫描/无有效文本明确失败 |
| 文件 | PDF 20 MiB、图片 10 MiB；最多 20 百万像素；项目材料合计 100 MiB |
| 体验 | 4—6 个场景；必要任务 1—6；最多 12 个布尔标记 |
| 排序 | 每题 2—6 元素，接受所有合法偏序排列 |
| 活动任务 | 每项目仅一个 queued/running/waiting_input 生成或修订任务 |
| 修复/调用 | 两轮修复；最多 12 次模型调用，含所有重试 |
| 自动执行 | 活跃总墙钟初值 600 秒；单次模型 90 秒；等待用户不计入 |
| 状态搜索 | 最多 24,576 唯一状态，初始限时 5 秒；超限为 inconclusive |

文件和时间限额是本次新增可调整默认值，不是实测容量。变更须检查输入、预算、测试和部署。初期固定一个体验运行端运行时；具体依赖版本在首个应用提交锁定，不使用未核实的“最新版”。

12 次为一次生成 run 的共享预算，不是每个 Agent 各自拥有。实时对话有独立 ConversationBudget、会话/参与者/项目限额及全局费用约束；具体额度在模型选定时配置，未配置不能无上限开放。在线实时 AI 与离线资料版分别验收。

## 发布与试用

技术通过证明受限规格可运行；内容审核判断资料支持；学习效果另行研究。所有对外分享及正式导出须双门槛。草稿只在所有者私有预览或显式草稿导出使用。

评估参考原方案：20 份冻结材料、至少两轮，独立故障集另算；两轮修复内技术成功率探索目标 90%，首个预览探索目标中位数 180 秒。报告样本数、全部耗时和成本，不作为服务承诺。
