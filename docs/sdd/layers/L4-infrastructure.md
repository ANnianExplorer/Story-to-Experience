# L4 基础设施

> 范围：server/infrastructure 与部署适配。当前为待实现设计。

## 职责

实现 PostgreSQL 仓储、文件存储、模型 Provider、LangGraph checkpoint、解析器和 Node 执行适配。只在组合根读取配置并注入，不能令领域对象查询环境变量。

## 数据流

持久文件按内容哈希存储，数据库保存项目归属/授权；原文与可公开资源投影分开。Provider 返回 request_id、usage、费用状态和结构化结果，不直接写体验版本。

## 边界与禁止依赖

数据库约束与应用规则双层保护；未知错误上抛并记录关联 ID，不把损坏数据当空库。模型适配器无跨项目查库权限；存储路径由服务生成。

## 实施细节与检查

迁移有版本；扩展—回填—切读—收缩分阶段。备份同时包含数据库、文件、运行时和清单，需实际恢复演练才可验收。
