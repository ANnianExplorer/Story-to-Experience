# L5 隔离执行与交付

> 范围：apps/playtest、受限 TS CLI、预览/分享资源服务。当前为待实现设计。

## 职责

执行器消费冻结候选、清单、输入哈希与允许路径，输出有限结构报告。浏览器只按正常 UI 完成路径，不注入完成标记；测试专用快照只读。

## 数据流

Worker 提交候选 → 校验器生成路径 → Playwright 实际操作 → 截图/trace → 哈希报告 → 应用服务决定质量。分享/导出从固定版本生成受限投影。

## 边界与禁止依赖

执行器无模型密钥、宿主挂载、容器套接字或任意网络；输入不接受 shell 拼接、任意 URL/path。trace 可能含私有引文，仅所有者可读。

## 实施细节与检查

正式交付重新核验技术/内容和授权清单；资源与主页面都受同一令牌约束。静态包从本地静态服务器离线可玩，下载不可撤回。

按 [分层目录](README.md) 核对上下游，功能落点见 [功能设计](../features/README.md)，真实门禁状态见 [质量目录](../../quality/gates.md)。
