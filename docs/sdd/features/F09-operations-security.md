# F09 SDD：安全、部署、恢复与评估

> 设计基线；实现状态以 [登记表](../../feature-registry.json) 为准。
> 行为事实源：[本功能 SPEC](../../spec/features/F09-operations-security.md)。相关决策：[ADR-0001](../../adr/0001-modular-layered-architecture.md)、[ADR-0007](../../adr/0007-isolated-dual-gate-delivery.md)、[ADR-0008](../../adr/0008-evidence-driven-engineering.md)。

## 目标与非目标

用真实运行证据证明可部署和可恢复，记录隐私、成本与能力限制；自审不作为安全认证。

## 分层与所有权

跨层授权/日志；L4 迁移备份；L5 Compose/隔离/发布；质量门禁。依赖必须满足 [分层规则](../layers/README.md)，本功能不得成为跨层捷径。

## 主数据流

配置与密钥校验 → 迁移 → 离线固定样例 → 真实 Provider 最小调用 → 权限/沙盒/恢复演练 → 实际手机 → 冻结评估 → 发布或回退。

## 数据与契约

部署镜像/依赖锁、迁移号、运行时清单、备份清单、脱敏日志、评估输入及逐次原始记录；不要求学生姓名；对话内容按最小保留、脱敏、授权与删除策略处理。

公共 API、状态机和数据字段分别见 [API](../../spec/api.md)、[状态机](../../spec/state-machines.md)、[数据模型](../../spec/data-model.md)。

## 异常与竞争

缺生产身份/沙盒/恢复证据阻断公开发布；依赖缺失明确失败；日志或导出发现密钥立即撤销并修复，不保留在报告中。

## 回退与验收

应用切回兼容镜像；数据库收缩前保留备份并验证兼容；恢复要同时还原数据库与哈希文件，验证关联完整性。

执行对应 SPEC 的全部适用 AT，报告正常、负向和竞争行为。未来测试放入相关模块的 tests 与端到端套件；登记实现位置后再升级状态。当前不提供不存在测试文件的虚假链接。
