## 从 SANWA 提取

实际可见：偏米灰的浅底、深灰字、暖橙行动入口；错落的大幅实景图片；小圆角；彩色标题细节；黑白手绘人物与贴纸装饰；白底轻边框导航；标题与图片的编辑式组合。

叙境转译：浅底与大图用于品牌入口和项目封面；手绘器物/路径用于文化探索；三栏工作台用更规整的信息网格。保留亲和感，同时确保资料和审核信息可读。

## 从视频提取

实际可见：上方低饱和蓝绿海面到下方奶油白的过渡；网点/抖色颗粒；米色帆、深色船身、轻木色构件；简短深色文案和黑色按钮；拖拽部件时显示 0/4、2/4 等修复反馈；后段主页采用大量留白。

叙境转译：海盐蓝绿作为主色，奶油白作为底色，墨色承担正文与高强调文字；网点插画只进入开场/封面/轻量空态；体验参与者操作立即给状态与知识反馈。视频修船交互是灵感，不把拖拽修船新增为第四种 MVP 机制；排序仍提供按钮和键盘路径。

## 共同方向与本项目调整

| 项 | 采用 | 使用边界 |
|---|---|---|
| 配色 | 低饱和蓝绿+奶油白+少量暖橙 | 颜色值为叙境重新制定，不是参考网站的官方 HEX/采样复刻 |
| 排版 | 充足留白、清晰标题、小型英文/编号标签 | 中文正文完整可读；不把标题全做图片 |
| 图片 | 文化器物大图、适量手绘/网点纹理 | 使用授权或自建资产，不复制原站图片、视频帧或品牌素材 |
| 交互 | 有目的的拖动、点击反馈和小动画 | 不把必要操作锁在 hover/拖拽或动画结束后 |
| 动效 | 文字入场、场景转场、任务反馈 | 长时间编辑区域动效低，尊重系统减弱设置 |
| 首版主题 | 固定浅色 | 深色主题另行设计和验收，不自动反色并宣称支持 |

本规范取代上一轮建议中的泛化“青绿工作台”描述，按用户指定参考收敛。只参考表现方法，不把参考页面的产品文案、价格、权利或实现代码带入本项目。
