# 前端视觉与动效验收

本规范关联 F01-R05/F01-AT05（工作台）和 F04-R05/F04-AT05（体验运行端）。当前 Token 检查与样式预览不等于生产 React 或业务验收。

| 检查 | 预期 | 当前方式 |
|---|---|---|
| Token 一致性 | CSS 与 JSON 自动生成结果相同 | python scripts/check_ui.py |
| 指定颜色对比度 | 普通文字≥4.5:1；必要边界/焦点≥3:1 | 脚本逐对检查，不能代替真实页面组合 |
| 360/390/768/1024/1440 宽 | 无横溢、关键操作可见、源文可读 | 预览人工/浏览器检查；生产待实现 |
| 标题与微交互 | M01—M08 适用项有正常/减弱两种状态 | 已有 React/Motion 动态试作及 DOM 交互测试；真实动画观感/生产运行待验收 |
| 减弱设置 | 系统或本地 reduce 时无非必要运动/延迟 | 代码检查+真实浏览器媒体设置+控件测试 |
| 键盘与焦点 | 所有主操作可达、焦点可见、抽屉回焦、排序非拖拽 | 生产 AT 必须正常 UI 实测 |
| 动画独立于业务 | 禁动画/动画中卸载仍得到正确状态 | 引擎/API 回归+正常 UI 检查 |
| 动态文案 | 费用未知/等待补充/待审核真实显示 | F01 状态回归；预览仅使用显式样例 |
| 运行性能/离线 | 预算核对、无泄漏，真实手机和离线包可用 | 生产构建/trace/实际手机，当前 not_run |

## 可执行 Token 检查

scripts/check_ui.py 只使用 Python 标准库，验证 HEX、必需角色、显式前景/背景组合、动效上界和派生 CSS。修改 Token 后用 --write 更新 CSS，再运行无参数检查。修改成不合格对比度必须失败；不能删除颜色对来逃避检查。

现有 CI 增加此项。生产 React 首次落地仍需 typecheck/build、组件交互、reduced motion、键盘和适用浏览器回归；样式预览不作为 verified 的依据。
