文档结构约定：视觉数值以 tokens.json 为准，CSS 由脚本派生；动态页面以对应功能状态机为准，动效不产生第二套业务状态。当前已增加 React/Motion 设计试作，生产组件/运行时仍待实施。

第二轮根据用户反馈收敛：保留配色，减少等宽卡片、常规徽章与营销式占位；改用错位纸页、衬线标题、图版注记、开放分栏。动画必须在可操作样本中呈现，不能只写在规范里。实际检查边界见 [第二轮报告](../quality/reports/2026-10-31-frontend-v2.md)。
