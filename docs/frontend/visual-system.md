# 视觉系统：海盐与纸页

> 数值权威为 [tokens.json](../../packages/ui/tokens.json)，本页解释用途。颜色是对参考的本项目转译，没有声称获得原站设计源文件。

主色控制为明确操作与选中，不让所有卡片各有彩色边框；白面、留白、细分隔与字重构成层级。正文放在实色面板，颗粒/渐变不得降低文字实际对比度。顶部海面可以渐变，主要信息区不铺动态噪点。

## 字体与尺度

默认使用系统中文无衬线字体栈，优先 PingFang SC、Microsoft YaHei、Noto Sans CJK SC；不依赖外部字体服务完成首屏和离线包。主题标题可用已授权衬线字体，缺字体时有系统回退，正文始终无衬线。

正文 16px/1.7；工作台密集元信息 14px/1.5；标签 12px/1.5；面板标题 20px/1.4；页面标题 28px/1.25；入口标题 40px/1.2（手机 32px）。字重 400/500/600；不模拟不存在的粗体。来源正文和教学反馈不小于 16px。

文化体验入口可用独立 editorial 标题尺度：最大 64px，紧凑桌面 44px、移动 36px，取 Token 并按宽度收缩；衬线字重 400，不照搬到所有后台表单。图版中的装饰性英文注记可小于界面字号，但关键标签、来源和操作不能依赖这些注记。

文字最大阅读宽度 65ch，中文段落优先约 30—38 字宽；字号支持浏览器 200% 缩放，不用固定高度裁切关键文本。标题可以换行，按钮文本不因固定宽度截断。

## 间距、边框与图片

4px 基础节奏，使用 4/8/12/16/24/32/48/64px；一般卡片 padding 24px，手机 16px。控件圆角 8px、卡片 12px、抽屉 16px；pill 仅状态标签和少量轻操作。阴影仅浮层，普通卡片靠面与边线。

按钮视觉高度至少 40px，手机主要触控区域至少 44×44px；图标按钮有可读标签。焦点使用 2px sea-deep 实线、2px offset，不能只用颜色变化表达焦点。

封面图可用 4:3 或 16:10，器物尽量保留全貌；知识证据图不为审美裁掉关键内容。手绘和颗粒是有限静态资产，优先 CSS/SVG 原创装饰或已授权 raster；用户上传 SVG 仍按安全规范拒绝。授权字体/素材写进清单。

## 布局与断点

| 宽度 | 工作台 | 体验运行端 |
|---|---|---|
| ≥1280px | 材料 280px、预览 minmax(480px,1fr)、生成 320px；间距 16px | 场景主区，知识/来源可放侧栏 |
| 1024—1279px | 材料改抽屉，预览+生成两栏 | 主场景+可收起详情 |
| 768—1023px | 资料/预览/生成标签切换，单主区 | 单列、详情抽屉 |
| 360—767px | 单列标签、主要动作就近；避免全屏固定大侧栏 | 一屏一任务，安全区留白，来源底部抽屉 |

容器 padding 24px/16px，禁止横向溢出；排序移动按钮/提交按钮在视觉和 DOM 顺序上合理。抽屉不遮住唯一退出入口，弹层 focus trap、Esc 关闭并返回触发元素。安全确认和内容审核不做戏剧性转场。

## 工作台与体验参与者端的密度

工作台强调长期编辑和核对：静态浅底、清晰分栏、紧凑状态。体验参与者端强调探索：可用插画、章节标题、有限文字入场和任务完成反馈。两者使用同一 Token，不强行让每个后台表单变成故事场景。

入口不以“左侧口号+右侧图形+下方三张等宽卖点卡”作为默认模板。可用非对称图版、轻微错位纸页、开放分栏和编号细线建立节奏；文化器物应有具体形态与注记，不用无关小图标填满画面。工作台因实际任务需要的分栏仍保留，不为了去模板而牺牲信息清晰度。
