# 发布验收与回退

首版发布前必须有以下实际证据，不能只勾选文档：

- F10 专业 Agent 计划、真实委派/工具/交接及失败恢复轨迹；F11 创作对话、体验导览/角色连续追问、RAG 出处、作用域和配额实测。
- 生成与对话成本分别记录，回答首字/整轮延迟实测；在线完整版与无实时 AI 的离线资料版明确区分，不用固定问答代替 AI。

- 所有对外交付需求有实现位置和对应验收报告，类型/构建/边界/适用测试通过。
- 新授权资料真实生成、记录 Provider/模型 ID/用量；mock 和预置样例与真实运行分开。
- 状态检查完整通过，真实 UI 关键路径/错误/重玩通过；至少一台实际手机完成。
- 内容审核覆盖关键陈述、答案和解释，许可有效，正式交付双门槛生效。
- 跨项目负测、上传/提示注入/脚本/沙盒/分享资源撤销均通过。
- Worker 重启、旧 token、重复投递、取消竞争、预算停止和费用未知已验证。
- 正式 ZIP 无密钥/私有全文/内部提示和日志，断网通过本地静态服务器完成；草稿标记明确。
- 生产身份、域名/CSP/TLS、持久卷、依赖锁和镜像清单齐全；实际备份恢复与回退演练通过。
- 数据保留/删除期限、责任人和内容审核人已确定；未发现未处理高优先级缺陷。

发布报告记录版本/提交、Schema/runtime/素材哈希、迁移版本、全部门禁、实际环境、剩余非关键风险与负责人。关键门禁失败或未执行不能标 released。

回退优先撤销受影响分享→选回合格稳定版→部署兼容镜像。数据库只能在确认兼容后回退应用；需恢复数据时先在隔离环境验证备份和文件哈希。已下载静态包不可远程撤回，应通知实际接收者；发送通知仍需明确用户授权。
