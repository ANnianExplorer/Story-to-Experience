## 本轮暴露并修复的缺陷

| 缺陷 | 表现 | 修复 |
|---|---|---|
| 引用未定义的 CSS 变量 | `--xj-space-20/40` 不存在，`padding` 整条失效，按钮被压成 36×29 | 改用已定义档位；`check_ui.py` 增加「未定义变量必须失败」 |
| 手写样式可能混入颜色字面量 | 会出现第二套调色板 | `check_ui.py` 增加「不得出现 HEX/rgb()/hsl()」 |
| 刷新后资料状态丢失 | 页面显示「尚未上传资料」，而服务端仍有文档 | 新增 `GET /projects/{id}/sources` 并在加载时恢复 |
| 非信封错误不可读 | 界面显示「请求失败。UNKNOWN」 | 客户端按状态码给出可行动文案 |
| 审核覆盖范围错误 | 提交审核必然 422 | 改为使用所选版本绑定的事实 |
