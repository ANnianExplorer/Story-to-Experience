# ADR-0004：受限 DSL 与共享确定性引擎

> 补充／局部替代：[ADR-0010](0010-multi-agent-and-conversation.md) 已将多 Agent 与双端 AI 对话纳入核心。确定性规则仍保留；在线对话的 Provider、预算、状态与在线/离线交付边界以新决策为准。

- 状态：Accepted（开发设计基线，实施待完成）
- 日期：2026-10-31
- 适用功能：F03,F04,F05
- 检查：G03,G05；实际状态见 [门禁表](../quality/gates.md)

## 背景

自由 JS、Python 状态图和前端逻辑各自运行会带来执行风险与判定差异。

## 决策

限制热点/分支/排序，布尔标记仅 false→true，条件仅 all/any/not/flag_equals。引擎为 TS 纯函数；体验运行端与状态搜索共用。完成任务与跳转由显式动作控制；排序遵守偏序，不猜唯一全序。

## 替代方案

任意脚本最灵活但无法有效隔离和穷举；Python 重写状态机实现快但可能语义漂移；只看节点连通不能证明条件可满足。

## 代价与约束

首版无法表达背包数量、冷却、实时物理；新增任何影响解锁的状态维度必须扩展状态模型和检查器。独立手工预期避免共用错误一起通过。

## 复议条件

有授权真实场景证明现有 DSL 不足时，再评估新机制及状态空间成本。
