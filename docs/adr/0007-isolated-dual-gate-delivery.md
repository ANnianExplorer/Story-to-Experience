# ADR-0007：隔离执行与双门槛交付

> 补充／局部替代：[ADR-0010](0010-multi-agent-and-conversation.md) 已将多 Agent 与双端 AI 对话纳入核心。确定性规则仍保留；在线对话的 Provider、预算、状态与在线/离线交付边界以新决策为准。

- 检查：G07,G08；实际状态见 [门禁表](../quality/gates.md)

## 背景

技术可玩不等于文化准确；令牌页面撤销后若素材仍公开会泄露资料；试玩浏览器若带密钥会放大攻击面。

## 决策

私有预览、正式分享、草稿导出、正式导出分别授权；正式交付要求技术 passed 与内容 approved 且哈希一致。分享绑定固定版本，所有资源经同一令牌验证。试玩容器仅访问指定预览资源且无密钥/宿主挂载。

## 替代方案

全部产物公开托管便宜但泄露；仅隐藏按钮不能防越权；让模型执行终端或任意网址超出 MVP。

## 代价与约束

需要独立预览来源、CSP、令牌清理和资源投影。下载包与先前保存的副本不能远程撤销，必须明确告知。

## 复议条件

引入组织、多租户或外部插件时重新做威胁模型与授权设计，不能只扩枚举值。
