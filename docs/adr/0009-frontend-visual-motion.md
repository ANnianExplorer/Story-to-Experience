# ADR-0009：参考驱动的视觉系统与 React 动效

- 状态：Accepted（用户指定风格方向的开发基线，生产实现待完成）
- 日期：2026-10-31
- 适用：F01、F04，并约束其余前端页面
- 门禁：G01、G02、G05、G08

## 背景

用户明确认可 SANWA 页面，以及 Godly 615 视频的 UI/配色，并要求 React 动效、文字动画和微交互。原开发基线只有前端边界与部分交互要求，缺少统一视觉数值和动画语义。

## 决策

采用奶油白、海盐蓝绿、墨色、少量暖橙；借鉴编辑式图片布局、手绘和网点插画。Token JSON 为数值源，派生 CSS 共用。工作台低动效、体验运行端适量叙事表现；共享组件和主题位于 packages/ui。

CSS 负责简单控件状态，Motion for React 负责布局/场景动画，React Bits 仅按需审核源码。首版固定浅色主题，尊重系统和本地减弱模式；动画不控制业务状态。

## 替代与代价

通用后台默认主题落地快但缺乏叙境辨识度；逐页自由发挥难统一；直接复刻参考素材/交互不符合文化创作场景；多套 GSAP/Motion/WebGL 并用增加体积和生命周期复杂度。

本选择要求维护 Token、统一 motion presets、可访问性和性能检查；不能因为视觉相似就认定可用或已验收。参考视频修船不引入第四种 MVP 玩法。

## 复议与验证

原始参考与实际观察见 [参考分析](../frontend/references.md)，视觉/组件/动效分别在 [前端目录](../frontend/README.md)。F01-T04/F04-T04 落地生产组件；F01-AT05/F04-AT05 运行验收。新增复杂渲染、深色主题或无法满足性能预算时复议；引擎和证据规则不受主题改变。
