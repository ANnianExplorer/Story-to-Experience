# ADR-0006：不可变版本与受限补丁

- 状态：Accepted（开发设计基线，实施待完成）
- 日期：2026-10-31
- 适用功能：F05,F07,F08
- 检查：G04,G06；实际状态见 [门禁表](../quality/gates.md)

## 背景

局部修改容易覆盖稳定体验，旧基准竞争和审核复用会造成错误发布。

## 决策

版本内容不可变，报告/审核追加绑定版本与哈希。新生成与修复都产生子候选；修订请求含 base_version_id 与 revision_head 的 CAS。补丁仅允许白名单路径和 add/replace/remove/test，禁止改测试器、来源和权限。

## 替代方案

直接编辑当前 JSON 简单但不可审计；全量重新生成破坏局部稳定性；语义冲突自动合并无法可靠判断。

## 代价与约束

存储量增加，需内容寻址去重。恢复旧版仅移动选择/稳定指针并校验资格，不删除新旧历史。语义变化必须重审。

## 复议条件

版本体积成为实际瓶颈后评估增量存储，但不得改变不可变和可还原语义。

## 落地与验证

按 [总架构](../sdd/architecture.md)、[功能设计索引](../sdd/features/README.md) 和 [规格目录](../spec/README.md) 实施；需求/任务/验收由 [登记表](../feature-registry.json) 连接。门禁待建不算通过；发布须保存真实执行证据。
